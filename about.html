🌾 About Smart Agriculture

Smart Agriculture Crop Recommendation System is a Machine Learning based web application that recommends the most suitable crop based on State, Season, Soil Type, Nitrogen (N), Phosphorus (P), Potassium (K), Temperature, Humidity, pH and Rainfall.

Project Features

🌾

Crop Recommendation

Recommends a suitable crop using agricultural and environmental parameters.

🖼️

Crop Image

Displays the recommended crop with its corresponding image.

🌱

Fertilizer Recommendation

Provides fertilizer information for the recommended crop.

💧

Water Requirement

Provides information about the required water level for the crop.

🤖

Machine Learning Prediction

Uses a Machine Learning model to generate crop recommendations.
